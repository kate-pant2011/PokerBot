# ADR-0003: минимизация перемещений при шафле

- **Статус:** Proposed
- **Дата:** 2026-09-07

## Контекст

Текущий `/shuffle` полностью случайно перестраивает отображаемые группы и не сохраняет перемещения. Для живой игры каждое лишнее перемещение создаёт паузу и путает участников.

## Предлагаемое решение

Планировщик сначала определяет допустимые целевые размеры столов, затем минимизирует число участников, чей `table_id` меняется. Случайность используется только для выбора между планами с одинаковым минимальным числом перемещений.

План сохраняется и применяется отдельной идемпотентной операцией. История `SeatAssignment` позволяет объяснить, кто и почему был перемещён.

## Последствия

- Полный random reshuffle перестаёт быть default.
- Clock/random source должны быть управляемыми в тестах.
- Нужно отдельно решить, когда закрывать стол, каковы допустимые размеры и нужен ли preview/подтверждение организатора. До этого ADR остаётся Proposed.

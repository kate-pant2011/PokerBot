# ADR-0002: ожидание группы опоздавших

- **Статус:** Proposed
- **Дата:** 2026-09-07

## Контекст

Если физически можно открыть новый стол, немедленная подсадка каждого опоздавшего мешает собрать минимальный стол из пяти. Бесконечное ожидание также неприемлемо.

## Предлагаемое решение

Первый опоздавший открывает сохранённый `LateArrivalBatch` с deadline. При достижении пяти человек до deadline создаётся новый стол. При timeout неполная группа рассаживается по наименее заполненным действующим столам.

Окно настраиваемое на уровне турнира; значение 2 минуты рассматривается как начальный default, но ещё не принято.

## Последствия

- Batch и deadline хранятся в БД и переживают рестарт.
- Достижение пяти и timeout конкурируют за один атомарный переход состояния.
- Требуются idempotency, блокировка и worker для просроченных batch.
- До перевода ADR в Accepted нельзя фиксировать default `W=2 минуты` как предметное правило.

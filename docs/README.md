# Документация PokerBot

Эта директория — карта контекста для разработчика и Codex. Она специально разделяет факты о работающем `@TiltClub_bot` и требования к следующей версии.

Текущее состояние проверено по commit `ed5ce0617dc8ebfee4f7a396153a4a813647cf79` от 27 августа 2026 года.

## Статусы утверждений

- **Current** — наблюдаемое поведение кода на указанном commit.
- **Accepted** — согласованное целевое решение, которое можно реализовывать.
- **Proposed** — предложение, требующее подтверждения до реализации.
- **Open** — вопрос без выбранного решения.

## Правило обновления

Изменение существующего поведения сначала отражается в `current/`. Новое предметное решение сначала меняет `target/`, сценарии и при необходимости ADR, затем код. После полной миграции legacy-описание удаляется или переносится в историю, а целевое описание становится текущим.
